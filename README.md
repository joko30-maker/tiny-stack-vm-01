A tiny stack virtual machine in one TypeScript file: wrapping 32-bit integers, a
256-value data stack, a 64-deep call stack, 256 words of memory, byte input and
output, and the ISA's ten traps with their own exit codes. It runs every program
of a set in one pass and writes each program's output bytes and exit code.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
